# PennyPilot — Personal Finance Dashboard
**Developer:** Rohaib Javed

PennyPilot is a sleek, modern personal finance tracker application designed to help users take full control of their income, expenses, and personal savings.

## 🚀 Features

- **Financial Dashboard:** Real-time metrics showing total balance, income, and expenses.
- **CRUD Operations:** Full capabilities to Add, Edit, and Delete income and expense items.
- **Categorization:** Classify transactions into Food, Travel, Shopping, Bills, Salary, or Custom Categories.
- **Data Visualizations:** Interactive charts built using Chart.js displaying income vs. expense ratios and expense distribution by category.
- **Search & Filters:** Instantly search through transaction histories and filter records by type and category.
- **Local Storage Integration:** Automatic persistent data storage in your web browser.
- **Data Export:** Export all transaction records to CSV.
- **Responsive Layout:** Tailwind CSS layout tailored for mobile, tablet, and desktop views.
